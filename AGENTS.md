# Agent operating rules

1. Read `PROJECT_STATE.json`, `docs/ROADMAP.md`, `docs/DECISIONS.md`, and the
   complete approved specification before changing the project.
2. Complete at most one pending milestone per calendar day in
   `America/New_York`. Setup and repair work must not silently advance another
   milestone.
3. Work only on the first milestone whose dependencies are complete.
4. Run milestone-appropriate tests before marking it complete.
5. Update state, progress, and the append-only decision log in the same commit.
6. Push one reviewable commit or pull request. Never force-push or rewrite
   published history.
7. Never commit secrets, cookies, applicant data, or restricted full job text.
8. Obey access controls, source terms, robots directives, and rate limits. Do
   not bypass authentication, CAPTCHAs, or blocking.
9. Human-only gates remain human-only. Agents may publish explicitly marked
   drafts but must not assert human approval.
10. Stop and record a blocker before changing study scope, eligibility rules,
    taxonomy meaning, publication status, legal assumptions, or mandatory
    quality thresholds.
